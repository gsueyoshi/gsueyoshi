## 取り組んでいること

普段は、Webアプリケーションの実装や、日々の作業を少し楽にする自動化ツールづくりに取り組んでいます。  
「こういう仕組みがあると便利そう」という段階のアイデアを、まずは動く形にしてみて、そこから少しずつ使いやすく整えていく進め方が中心です。

技術としては、JavaScript / TypeScript / React を使ったフロントエンド寄りの開発に加えて、Python や Google Apps Script を使った自動化、AWS Lambda を活用したサーバーレスな処理などにも触れています。  
最近は、AIをコーディングや試作の補助に取り入れながら、開発速度と品質のバランスを探ることにも関心があります。

## 開発で大事にしていること

開発では、最初から大きく作り込むよりも、まず小さく作って早めに試すことを大切にしています。  
実際に動かしながら改善点を見つけて、あとから手を入れやすい形に整えていくほうが、自分には合っていると感じています。

また、コードそのものだけでなく、READMEや補足説明もできるだけ分かりやすく書くように意識しています。  
自分が後から見返したときにも扱いやすく、他の人が読んでも流れを追いやすいリポジトリを目指しています。

## GitHubについて

このGitHubでは、学習用の記録だけでなく、実際に動かせるものや、試作の過程が分かるものも残していきたいと考えています。  
完成したものを置くだけでなく、試しながら改善していく流れも含めて、自分の開発の積み重ねが見える場所にしていくつもりです。

そのため、実装サンプル、業務改善のための小さなツール、AI活用の検証コードなど、実用性や再利用しやすさを意識した内容を少しずつ公開しています。
